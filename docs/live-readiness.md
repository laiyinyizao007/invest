# 实盘准入清单(Phase 6,人工步骤)

> **结论先行:按当前证据,不应该上实盘。**
> 日线趋势策略在玉米上**没有发现可延续的优势**,旧回测还受换月跳空污染;晋级门槛(`docs/adr/20261109-promotion-gate.md`)一项都没通过。
> 15 分钟基准(用购买的分钟线重做,见 `docs/adr/20261110-baseline-15m.md`)的结论**同样是负面**:测试段 -20.2%、夏普 -1.08,成本吞掉了全部毛利。
> 本清单是"将来某个策略通过门槛之后"的流程,而不是现在就去做。实盘切换需要用户另行明确授权。

## A. 策略准入(代码与数据,我可以做)
- [ ] 数据已复权(`CADJ/MAADJ`),并有足够长的样本外(见晋级门槛 ADR 的最少年数表);
- [ ] 通过晋级门槛全部 8 条(`risk/promotion_gate.py::check_gate` 输出为空);
- [ ] 随机入场对照分位 ≥ 95%,成本翻倍后夏普 ≥ 1.0;
- [ ] 测试段只看过**一次**,看后没有再调参;
- [ ] 回测成本换成期货公司**真实费率**(不是"3 元/手"的假设)。

### A2. 新候选策略的额外约束(2026-11-10 起生效)
- [ ] **最终确认必须用新的样本外数据**:15 分钟基准已经用掉 2024-01 ~ 2026-06 这一段,
      再拿同一段做最终确认不成立(研究者已知其结果,构成多重检验偏差)。可用的新证据只有:
      ① 2026-06 之后补购的分钟线;② SimNow/小额实盘的真实成交记录;③ 其它品种的独立数据;
- [ ] 新候选在训练/验证段筛选时的**基准分数**必须明显高于两条已建基准(见 ADR 的成绩单),否则直接淘汰;
- [ ] **样本量仍受限于数据长度**:现有分钟线约 5.9 年,夏普 95% 置信区间下界 > 0 这一条在 2~3 年样本外上基本不可能通过;
      要么接受"只能证明不了优势"这一结论,要么通过多品种/多周期/实盘记录累积证据,**不能靠放宽门槛**。

## B. SimNow 准入(见 `docs/runbook-simnow.md`)
- [ ] 连续 ≥ 5 个交易日无人值守,含夜盘与周末;
- [ ] 手册第 5 节 10 项实测全部完成并回填;
- [ ] 告警全部到达。

## C. 期货公司与穿透式监管认证(只有你能做)
> 以下流程基于一般做法,**具体以你开户的期货公司为准**,2025 年起程序化交易还有报备规定,请向对方确认。

1. 开户前向客户经理确认:
   - [ ] 是否支持 CTP 程序化接入?AppID / AuthCode 怎么申请?
   - [ ] 申请与测试环境是否收费?
   - [ ] 程序化交易是否需要报备?怎么报?
   - [ ] 程序化账户的手续费、保证金、**最低入金**有没有特殊规定?(1 万元能否开户)
   - [ ] 测试环境要跑多久才能开通生产环境?
2. 登记你的程序(软件名称、版本),拿到测试环境账号与 AppID/AuthCode;
3. 把 `.env` 的 `CTP_ENVIRONMENT` 设为 `测试`(看穿式测试环境用测试版 API),在测试环境跑满对方要求的天数;
4. 通过后获得生产环境的 AppID/AuthCode,`CTP_ENVIRONMENT` 改回 `实盘`。

## D. 首次实盘(满足 A、B、C 之后,且经你明确授权)
- [ ] 固定 1 手;账户级风控参数按 1 万元设置(当日 600 / 累计 2000);
- [ ] 先在**非交易时段**连通并核对账户权益、持仓、可用资金;
- [ ] 第一周只在白天盯着运行,夜盘稳定后再无人值守;
- [ ] 把真实滑点、手续费、成交与回测假设对比,偏差大就回到 A 重做;
- [ ] 出入金前先停机(权益变化会被风控当成盈亏)。

## E. 永远成立的纪律
- 不手动改止损、不手动提前平仓、不在账户里手动开仓(对账会拒绝启动);
- 触发硬锁定后先查明原因,不要立刻解锁;
- 连续多次触发当日熔断说明策略或行情假设已失效,回到 A 重新验证,不是调大阈值。
