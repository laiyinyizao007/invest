# ADR: 策略晋级门槛(进入 SimNow 长期挂机 / 实盘前必须全部通过)

- 状态:已采纳
- 日期:2026-11-09
- 跟踪:Issue [#1](https://github.com/laiyinyizao007/invest/issues/1)
- 实现:`risk/promotion_gate.py`,测试 `tests/test_promotion_gate.py`

## 背景
用户给出一组经验门槛(样本外夏普 > 1.5、最大回撤 < 20%、交易次数 > 150)。方向合理,但有统计上的缺口:
- 夏普的估计误差很大。按 Lo (2002) 的近似,年化夏普标准误 ≈ √((1 + SR²/2) / 年数)。
  3 年样本外、夏普 1.5 时标准误约 0.84,95% 区间约 [-0.15, 3.2]——**不能排除策略没有优势**。
  从大量参数组合中挑出的最优结果,误差还会更大(多重检验)。
- 回测夏普比实盘高是常态,"打五折"只是经验口径。
- 15 分钟线目前只有约 2.5 个月数据,"3 年 / 150 笔"现在无法检验。

## 决策
候选策略必须**全部**通过以下门槛,才有资格进入 SimNow 长期挂机;通过只代表"有资格接受下一阶段检验",不代表策略有效:

| # | 门槛 | 阈值(默认) | 来源 |
|---|---|---|---|
| 1 | 样本外夏普 | ≥ 1.5,且 ≤ **上限(N, T)** | 用户;上界口径见 `20261117-dsr-consistent-suspicious-sharpe.md`(兜底 3.0) |
| 2 | 夏普 95% 置信区间下界 | > 0 | 本 ADR 新增 |
| 3 | 最大回撤 | < 20% 且 ≤ 2000 元 | 用户 |
| 4 | 样本外往返笔数 | ≥ 150 | 用户 |
| 5 | 超过随机入场对照的分位 | ≥ 95% | 本 ADR 新增 |
| 6 | 成本翻倍后的样本外夏普 | ≥ 1.0 | 本 ADR 新增 |
| 7 | 回测数据已复权 | 必须 | 本 ADR 新增 |
| 8 | 最优参数位于参数高原 | 必须 | 本 ADR 新增(优化器邻域平滑) |

通过后仍须:SimNow 连续无人工干预运行足够长时间(含夜盘、断线重连、风控触发)后,才讨论实盘。
实盘切换需用户另行明确授权。

## 样本外长度与置信区间的张力(须在看到任何候选结果之前面对)
夏普 95% 置信区间下界 > 0 要求样本外年数 Y > z²(1 + SR²/2)/SR²(z = 1.96):

| 样本外夏普 | 所需最少年数 |
|---|---|
| 1.0 | 约 5.8 年 |
| 1.5 | 约 3.6 年 |
| 2.0 | 约 2.9 年 |
| 3.0(旧口径下已属可疑) | 约 2.4 年 |

含义:**单段 1 年样本外,哪怕夏普 1.5 也不能排除没有优势**(区间约 [-1.4, 4.4])。购买的约 4 年 15 分钟数据若按"3 年训练 + 1 年盲测"切分,
本门槛第 2 条几乎不可能满足。可行的出路(须在看到结果前选定,不得事后放宽阈值):
1. 滚动时间窗(walk-forward),把多段样本外拼接,使总样本外长度 ≥ 所需年数;
2. 把 SimNow / 前向数据作为额外的、真正未被看过的样本外,累计到所需年数;
3. 明确接受"该门槛在现有数据下无法通过"——这本身就是诚实的结论。
