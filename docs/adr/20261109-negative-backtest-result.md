# ADR: 如实记录"日线趋势策略在玉米上未发现优势"并固定方法学纪律

- 状态:已采纳
- 日期:2026-11-09
- 跟踪:Issue [#1](https://github.com/laiyinyizao007/invest/issues/1)

## 背景
Phase 2 实现了日线双均线 + ATR 移动止损策略(`strategies/trend_atr_strategy.py`)与网格优化器(`scripts/optimize.py`)。
需要决定:如何解读回测结果,以及此后每个新策略想法必须遵守的验证流程。

## 结果(玉米 C,日线,1 手,成本为假设值:每边 1 个最小变动价位 + 3 元/手手续费)
- 默认参数(10/40/1.5)全历史:-59%,胜率 25.6%,平均盈 315 元/平均亏 167 元,每笔期望为负。
- 训练段(2005–2018),204 组参数:夏普为正约 36%,中位数约 -0.1。
- 验证段(2019–2022),有交易(往返 ≥ 5 笔)的 84 组:夏普为正 15%,中位数 -0.49;
  训练段与验证段夏普的相关系数仅 0.13——训练段表现几乎不能预测验证段。
- 训练段选出的参数(10/100/1.75):训练 +36%、夏普 0.51;验证段仅成交 **1 笔**,无统计意义。
- 甲醇(MA):数据自 2014 年末起,训练段仅四年,且 300 元预算下绝大多数日子无法开仓,优化器无合格组合而放弃。
- 测试段(2023 年起)**未查看**。

## 决策
1. **结论表述为"未发现可延续的优势 / 无法证明优势",而不是"已证明无优势"**:验证段交易笔数太少,统计效力不足。
2. 每个新策略想法必须走同一流程:训练段选参 → 验证段检验 → 方向最终确定后**测试段只看一次**,看后不得据此再调参。
3. 选参用邻域平均得分而非单点最高分:只有周围完整 3×3×3 邻域的格子才能被选,网格内无效邻居按 0 计,
   边界格子不参与(边缘格子邻居更少、更近,平均值系统性偏高)。
4. 必须配随机入场对照(`strategies/random_entry_strategy.py`:出场规则与风险预算相同,仅入场随机),
   检验入场信号相对随机有无真实贡献。
5. 网格试得越多越容易挑中运气好的组合,不得在看到验证段结果后回头扩大/调整网格。

## 已知的结论可信度限制
- **主力连续合约未复权**:新浪的 `XX0` 在换月处价格跳空,会污染 ATR、均线交叉与止损;
  所有回测结论的可信度都因此打折扣(甲醇尤甚)。严肃验证前应构建复权连续合约。(最高优先级数据隐患)
- 日线内高低点先后顺序未知,移动止损按当根极值收紧、下一根生效,属日线固有近似。
- 回测成本是假设值,实盘前必须换成期货公司真实费率。
- 分钟线每个周期只返回最近约 1023 根(15 分钟线约 2.5 个月),无法做分钟级样本外验证,须长期增量积累。

## 更新(同日):换月跳空已量化,上述回测结论作废待重做
`scripts/build_continuous.py` 用分合约日线构建了差价法复权的主力连续合约(仅 2018-05 起,新浪分合约日线的覆盖范围),
并量化了换月价差(23 次换月,价差均为精确值,未出现非正价格):

| | 换月价差中位数 | 最大 | 对比 300 元预算 |
|---|---|---|---|
| 玉米 C | 约 44 点 = 440 元/手 | 145 点 = 1450 元 | 中位数就大于整个止损 |
| 甲醇 MA | 约 75 点 = 750 元/手 | 311 点 = 3110 元/手 | 远大于整个止损 |

未复权的 `C0`/`MA0` 在每次换月处混入一个**与整个止损同量级甚至更大**的假跳空,并抬高 ATR(甲醇日 ATR 未复权约 152 点,复权后约 56 点)。
因此上面所有基于 `C0` 的结果既不能证明有优势,也不能证明没有——**结论作废,须在复权数据上重做**。

复权数据只到 2018-05,旧的三段切分(训练 2005–2018)无法使用。重做前**先于任何结果**确定新的切分:
训练 2018-05–2021-12 / 验证 2022-01–2023-12 / 测试 2024-01 起(测试段此前从未被查看)。
日线只有约 8 年,往返笔数仍会很少(约 20~30 笔),统计效力依旧不足,晋级门槛不可能靠日线达到。

## 样本切分的补充纪律(2026-11-09 用户补充,已与现有方法对齐)
- 必须按**时间顺序**切分,绝不随机打乱;不能用未来数据去"预测"过去。
- 测试(盲测)段一旦被反复查看两次以上,就物理上降级成训练区,失去验证能力。
- **同一个测试段不能被多个候选策略依次使用**:第一个策略在测试段失败后,换第二个策略再跑同一段,等于把测试段当训练集用了。
  每多试一个候选,就该把它计入试验次数并降低可信度;更稳妥的做法是为后续候选准备新的留出数据(如 SimNow 往后积累的前向数据)。
- 训练区应覆盖完整的行情环境(含长时间震荡),但**区间必须在看到结果之前确定**,不能事后挑选。
- 优先使用滚动时间窗(walk-forward):把多段样本外结果拼接评估,总样本外长度比单段 1 年更有说服力(见 promotion-gate ADR)。尚未实现。

## 影响
- 暂停策略研发,优先建设执行通道与风控基础设施(Phase 3–5),待 15 分钟线积累足够、数据复权后再回到策略研发。
- 不在没有样本外证据的策略上开实盘。

## 验证

## 回滚
无需回滚;若后续有新证据(复权数据、更长的分钟线)改变结论,新增 ADR 取代本条。
