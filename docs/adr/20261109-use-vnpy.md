# ADR: 采用 vn.py 作为交易与回测框架

- 状态:已采纳
- 日期:2026-11-09
- 跟踪:Issue [#1](https://github.com/laiyinyizao007/invest/issues/1)

## 背景
需要国内商品期货的自动交易能力。CTP 底层(C++ 封装)、穿透式认证、断线重连、并发处理自研成本高,且实盘风险大。

## 备选方案
1. **vn.py**(开源、纯 Python 上层、内置 CTP 网关、CTA 引擎、回测、风控插件)
2. 天勤 TqSdk(轻量、API 友好;高级功能/长周期数据部分付费)
3. 自研数据管道 + 回测引擎 + CTP 封装
4. adb 操控手机 app 下单

## 决策
采用 **vn.py**。理由:免费、国内期货事实标准、CTA 引擎与回测可直接复用,精力集中在策略与风控。

## 影响
- 需要 x86_64 环境跑 CTP(`vnpy_ctp` 无 aarch64 wheel),树莓派 5 不能直接承担实盘节点。
- `vnpy_riskmanager` 只做流控类限制,"单笔止损 / 盈亏比 / 连亏熔断"须在策略层自行实现。
- 拒绝方案 4:无可靠成交回报、易误点、有合规与封号风险。

## 验证
`import vnpy, vnpy_ctp, vnpy_ctastrategy` 在 Python 3.13 / Windows 下通过;SimNow 连通性在 Phase 4 验证。

## 回滚
策略代码集中在 `strategies/`,与框架耦合面窄;可改接 TqSdk。
