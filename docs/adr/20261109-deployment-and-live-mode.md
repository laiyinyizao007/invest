## 1. 策略的实盘模式(同一份逻辑,两种运行方式)
- 回测:引擎直接推送日线,收盘后产生信号并立即挂单,下一根成交。
- 实盘:引擎推送 Tick,`BarGenerator` 合成日线(夜盘并入次日)。
  - vn.py 的分钟线时间是**开始时间**,15:00 收盘的最后一根是 `14:59`,所以 `daily_end = 14:59`(设成 15:00 永远不触发)。
  - 收盘时已休市,下单会被拒绝并触发"废单锁仓"。因此**信号先存起来,下一个交易时段的第一个 Tick 才发委托**,只发一次。
  - 若 14:59 那一分钟没有成交,日线不会自然完成、下一交易日会被静默并入同一根日线。已加保护:发现分钟线跨到新交易日时强制完成上一根。
  - 进程在盘中启动时当天日线缺前半段,识别后丢弃(日志提示)。
- 状态持久化与重启恢复:持仓、入场价、移动止损内部状态通过 `sync_data()` 在每次成交和每根日线后保存;重启后由 CTA 引擎恢复。
  本地止损单不随进程保存,恢复后在第一个 Tick 重新挂出,并立刻检查一次(重启时价格已击穿止损应立即离场)。
- 历史预热从本地数据库读取,代码由 `history_vt_symbol` 指定(实盘交易具体合约,历史存在 `CADJ` 等连续合约代码下)。
  数据库需每个交易日收盘后由 `build_continuous.py --save` 更新。

## 2. 运行时的启动与对账
启动顺序(任一步失败都不进入交易):硬锁定检查 → 连接网关 → 等合约与账户 → 主动查询持仓并等待稳定 → 初始化策略并**强制停止**
(引擎会把保存的 `trading=True` 恢复出来,必须压住)→ 撤销遗留委托 → **对账** → 启动策略。

对账失败(任一成立即拒绝启动,退出码 4):账户有不属于本策略合约的持仓;策略恢复出的持仓与账户净持仓不一致;策略状态自相矛盾。
理由:带着错账本交易比不交易更危险。

运行中看门狗:策略被引擎异常停止(CtaEngine 捕获异常后只写日志,本地止损随之失效)→ 立即 FATAL 告警并紧急平仓;
交易时段内行情停更(本地止损依赖 Tick)→ 告警;可选心跳。

## 3. 退出码与自动重启语义
| 退出码 | 含义 | 容器行为(`restart: on-failure:3`) |
|---|---|---|
| 0 | 正常停止;硬锁定后已确认空仓;启动时发现硬锁定 | **不重启**(避免"硬锁定后被自动拉起继续交易") |
| 2 | 配置错误 | 重启无意义;最多 3 次后停止 |
| 3 | 启动失败(连不上、超时) | 重试最多 3 次 |
| 4 | 对账失败 | 需人工处理;最多 3 次后停止 |
硬锁定但平仓失败时**进程保持存活**并持续告警,不退出(带持仓杀进程会让持仓失去本地止损)。退出时仍有持仓会发 FATAL。

## 4. 通知(`notify/webhook.py`)
非阻塞(有界队列 + 后台线程),失败 1/3/5 秒重试后只记录,不影响交易;相同消息 60 秒内去重(FATAL 不去重);
队列满时丢弃非 FATAL,FATAL 挤掉最旧的一条;发送前把密码、授权码、token 替换为 `***`(含 URL 路径里的 token——
`requests` 的异常文本只含路径,曾因此泄露 Telegram token,已修复并有测试)。支持 generic / 飞书 / Telegram。

## 5. 容器化
- 镜像基于 `python:3.13-slim-bookworm`(**x86_64**)。**`vnpy_ctp` 在 PyPI 上近几个版本只有 Windows 预编译包与源码包,没有 Linux 包**,
  所以 Linux 里是从源码编译,镜像装了 `build-essential`。树莓派 5(ARM64)不行。
- 非 root(uid 1000)运行;`.vntrader`(策略状态、日志、数据库)与 `data`(风控状态文件、心跳)通过卷挂载持久化。
  **宿主机上的挂载目录需让 uid 1000 可写**(`mkdir -p runtime/vntrader runtime/data && chown -R 1000:1000 runtime`)。
- HEALTHCHECK:运行时每 10 秒刷新 `data/state/heartbeat`,超过 120 秒没刷新视为不健康(启动宽限 240 秒)。
- 凭据只通过 `env_file: .env` 注入;镜像里没有 `.env`(`.dockerignore` 排除)。
- `stop_grace_period: 60s`、`init: true`,让 `SIGTERM` 能走优雅停止。
