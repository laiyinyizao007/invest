### 2.3.2 研究文档的矛盾与证据强度——本项目的采纳口径

研究文档是一次 AI 对话的导出整理,里面有互相矛盾的数字和缺少出处的断言。**以下是本项目的采纳口径,以代码与 ADR 为准,不以研究文档为准。**

**A. 文档内部矛盾**

| 矛盾 | 研究资料的说法 | 本项目采纳 | 出处 |
|---|---|---|---|
| 连亏熔断阈值 | 提问 15「连亏 3 笔就停」 vs §2.3/§3.5「日内连亏 2 单(600 元)」 vs 账户层「当日回撤 600 元」 | 以**账户级**当日 600 元 / 累计 2000 元为准;策略层 `DailyLossGuard` 只对日内策略有意义 | `risk/account_guard.py`、ADR account-risk-lock |
| 止损比例 | 固定 2% / 1.5% 立即退出 + 2% 追踪 / 3% 或 300 元;网格寻优里止损参数又可调 | 单笔预算 300 元(3%)是**约束**;ATR 倍数是形状参数可寻优,止损放不下预算则弃单,不放宽预算 | ADR risk-floor-immutability |
| "止损永不变动" vs "止损参数可优化" | 同上 | 同上:预算与"只收紧不放松"不可优化,入场/出场形状参数可优化 | 同上 |
| 盲测统计力 | §3.3「3 年训练 + 1 年盲测够用」 vs 同节「单段 1 年盲测统计力不足,门槛几乎无法满足」 | 采用夏普 95% 置信区间下界 > 0 的硬要求;样本不足如实记"无法证明优势",**不放宽门槛** | ADR promotion-gate、live-readiness A2 |
| 夏普门槛口径 | 夏普 <1.0 淘汰 / 铁三角样本外夏普 >1.5 / 筛选表「≥1.0」 | 以 `GateThresholds.min_oos_sharpe=1.5` 为准;研究资料里的 1.0 淘汰线本项目未单独实现 | `risk/promotion_gate.py` |
| 上线顺序 | 「没通过样本外测试的策略不要去实盘交学费」 vs 「实盘单开 1 手验证通道和心魔」 | SimNow 先行 + 实盘准入检查(生产 API 需批准文件);实盘通道验证不得早于门槛通过 | `risk/live_admission.py` |

**B. 证据薄弱的断言**

| 断言 | 评价 | 本项目处置 |
|---|---|---|
| 胜率 >60% 必过拟合(剪枝线) | 对趋势策略是经验法则,无出处 | 未采用为硬剪枝 |
| 夏普 >3 必是代码错 | 强经验阈值,非定理 | `GateThresholds.max_suspicious_sharpe=3.0` 仅作为"先排查前视/过拟合再决定"的触发,不当作结论 |
| 夏普区间 [-1.4, 4.4]、需 3.6 年样本等数字 | 对话里的估算,无推导 | 门槛用 Lo(2002) 公式 `sharpe_ci` 重算,不引用原数字 |
| 实盘夏普通常只有回测的 50% | 无出处 | 不作为门槛 |
| 对资金不足循环重试会被上期所 1 分钟内封 IP | 无来源,带夸张 | 只采纳合理内核:开仓永不自动重试 |
| 错误码硬/软分类、60 秒假死、1/3/5 秒退避 | 未引用官方码表 | 只认 SimNow 实测或官方码表背书的码(ADR ctp-error-code);假死阈值取自运行时配置 |
| AI 矿工 / 状态路由(§6)的"挖到策略"叙事 | 没有实证;同一数据上让 LLM 反复迭代恰是多重检验问题 | 外层只经沙盒 API、产出只落 pending、`promotion_gate` 是唯一闸门、装载永远人工(ADR bisheng-ai-researcher) |
| 论文/书籍获取渠道(含版权存疑的站点) | 与系统无关,有合规问题 | 不纳入项目文档 |
